# Upstream documentation snapshot — USDA NASS Quick Stats

Source of truth for every endpoint wrapper (ADR-0003). The files in this directory are
written by `scripts/refresh_upstream.py` (`/refresh-upstream`) from the pages in the
table below and refreshed deliberately by PR, so that changes show up as diffs. This
file is generated by the same script; nothing here is edited by hand.

## Attribution

The documentation states `NASS API Terms of Service`; `This product uses the NASS API
but is not endorsed or certified by NASS.`. The script stops when a page it reads states
one it does not record. The documentation's text is reproduced here as this package's
reference (ADR-0003); the publisher's objection is met by replacing it with a summary
that keeps the names and semantics the wrappers rely on.

## How this is captured

Both pages are server-rendered HTML; the api page's four tabs and the pop-ups of its
Usage tab are all in the page as served and shown by script. Each page's `div#indexbody`
is converted to Markdown with markdownify 1.2.3 (Beautiful Soup 4.15.0, html.parser),
headings, lists, code and tables kept and underscores left unescaped, so that names read
as upstream writes them. The masthead, the menu bar and the scripts outside it are left
out, and so are, inside it, the api page's tab menu, the pop-ups' Close(X) controls, the
key request form (its fields, its agreement question and a copy of the terms, which the
script checks against the Terms of Service tab) and the head of the Word document both
pages embed. The column-definitions table, which the api page embeds whole from
param_define, has merged cells, its four dimension rows spanning all three columns, so
both files keep it as HTML (conventions §3): its rows, and its cells with their colspan
and their text, whitespace collapsed and Word's styling left out. The attribution check
leaves out HTML comments, which a page does not print: both pages keep a 2008 copyright
footer commented out, which is therefore not recorded as stated.

Fetched is the UTC time the run started, in ISO 8601 with an explicit Z, the same for
every row. Bytes and sha256 are those of the body as fetched: a converted page's row
holds the HTML page's, an excerpt's the whole document's. Last-Modified is the HTTP
header in UTC, ETag as sent. A page recorded without a file is `(no file)`, and a body
that changes on every request records no size, sha256 or validators. Requests go one at
a time, 2 s apart, each retried at most once, identified as `xippios-usda-nass
refresh_upstream (+https://github.com/xippios)`; no API key is sent or read.
