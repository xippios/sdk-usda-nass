# Upstream documentation snapshot — USDA NASS Quick Stats

Source of truth for every endpoint wrapper (sdk-core ADR-0028). The files in this
directory are written by `scripts/refresh_upstream.py` (`/refresh-upstream`) from the
pages in the table below and refreshed deliberately by PR, so that changes show up as
diffs. This file is generated by the same script; nothing here is edited by hand but
`OBSERVED.md`, where it exists: what upstream does but never documents, each note with
its evidence.

## Attribution

The documentation states these, as printed:

- `NASS API Terms of Service`, printed at https://quickstats.nass.usda.gov/api: the
  Terms of Service tab of the api page, and a copy in its key request form
- `This product uses the NASS API but is not endorsed or certified by NASS.`, printed at
  https://quickstats.nass.usda.gov/api: the notice the Attribution section of those
  terms asks every service to display

The check reads past these words, which state none here: `Introduction Terms of Service
Usage`; `agree to the NASS Terms of Service`; `Do you agree with Terms of Service?`;
`subject to your acceptance of the terms and conditions contained herein`; `subject to
the terms and conditions of this Agreement`. How this is captured says why.

The script stops when a page it reads states one it does not record, or no longer prints
one it records. The documentation's text is reproduced here as this package's reference
(sdk-core ADR-0028); the publisher's objection is met by replacing it with a summary
that keeps the names and semantics the wrappers rely on.

## How this is captured

Both pages are server-rendered HTML; the api page's four tabs and the pop-ups of its
Usage tab are all in the page as served and shown by script. Each page's `div#indexbody`
is converted to Markdown with markdownify 1.2.3 (Beautiful Soup 4.15.0, html.parser),
headings, lists, code and tables kept and underscores left unescaped, so that names read
as upstream writes them. The masthead, the menu bar and the scripts outside it are left
out, and so are, inside it, the api page's tab menu, the pop-ups' Close(X) controls, the
key request form (its fields, its agreement question and a copy of the terms, which the
script checks against the Terms of Service tab) and the head of the Word document both
pages embed. The column-definitions table, which the api page embeds whole from
param_define, has merged cells, its four dimension rows spanning all three columns, so
both files keep it as HTML (conventions §3): its rows, and its cells with their colspan
and their text, whitespace collapsed and Word's styling left out.

The attribution check reads a page's visible text, so the 2008 copyright footer that
both pages keep commented out is not recorded as stated. It reads past the api page's
three references to the recorded terms, its tab menu's label, the Introduction's
agreement and the key form's question, and past two sentences of the terms that say
terms and conditions, none of which states anything new.

Fetched is the UTC time the run started, in ISO 8601 with an explicit Z, the same for
every row. Bytes and sha256 are those of the body as fetched: a converted page's row
holds the HTML page's, an excerpt's the whole document's, a file split from a page the
page's. Last-Modified is the HTTP header in UTC, or as sent in a code span where it is
no HTTP date, and ETag is as sent, in a code span, on a row that ends in a comment
telling the secret scan it is no key. A page recorded without a file is `(no file)`, and
a body that changes on every request records no size, sha256 or ETag. A sample is a
small answer of the API kept verbatim under `samples/`, which documents the answer's
shape and is no test fixture. Requests go one at a time, 2 s apart, through core's
client, each retried at most once and no sooner than 10 s, a 429 after the wait the
client gives it where that is longer, and are identified as `xippios-usda-nass/<version>
(+https://github.com/xippios)`, the source package's version in place of `<version>`. No
redirect to another host is followed and no browser is imitated. No key is sent or read.
A page an anonymous client cannot read is requested once and listed under Not fetched.
